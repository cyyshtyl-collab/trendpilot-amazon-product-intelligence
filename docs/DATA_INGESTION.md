# 免费数据接入规范

## 1. 当前接入方式

TrendPilot 同时保留免费 ASIN 录入和 Octoparse、卖家精灵 CSV/XLSX 导入；系统本身不自动抓取 Amazon 商品页。

1. Google Trends：每日自动同步免费公开趋势，直接写入市场信号池。
2. Amazon 候选：团队粘贴商品链接或 ASIN，单次最多 100 条。
3. 采集文件：上传 CSV/XLSX 或粘贴 CSV，按 `ASIN + 站点` 去重更新。
4. 人工复核：在商品编辑页核对真实名称、价格、BSR、评分和评论数。

## 2. ASIN 候选规则

- 支持 10 位 ASIN，或包含 `/dp/ASIN`、`/gp/product/ASIN` 的 Amazon 链接。
- 唯一键为 `ASIN + 站点`，重复提交会更新原记录。
- 新记录名称显示为“待核验商品 · ASIN”，结论为“观察”。
- 系统不猜测价格、BSR、评分、评论数、销量或毛利率。
- 未完成关键字段复核的商品不进入可决策周报。

## 3. 数据可信度

| 级别 | 条件 | 用途 |
| --- | --- | --- |
| 公开趋势 | Google Trends 等公开信号 | 发现方向 |
| 待核验候选 | 仅有 ASIN 或商品链接 | 任务排队 |
| 部分数据 | ASIN 与部分事实字段 | 初筛 |
| 可决策数据 | ASIN 有效，价格、BSR、评分、评论数至少三项完整 | AI 评分与周报 |

## 4. 真实性原则

- AI 只生成评分解释、痛点摘要和卖点草案，不生成事实指标。
- 价格、BSR、评分和评论数必须由团队核对，并保留最后更新时间。
- 不同站点、币种和搜索量周期不能直接混合比较。
- 候选数量不等于可决策数量，管理层页面默认只展示可决策口径。
