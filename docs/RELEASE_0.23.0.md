# TrendPilot 0.23.0

发布日期：2026-09-30

## 问题

阿里云 ECS 无法稳定出站访问 Google Trends。Google RSS 本身正常，但生产机直接
请求连续超时，导致页面显示“暂时不可用”，每日任务也只记录失败。

## 修复

- 增加 GitHub Actions 免费海外采集任务，每天北京时间 09:05 执行。
- 使用 Ed25519 对完整请求体和时间戳签名，ECS 仅接受五分钟内的合法数据。
- 私钥只存放在 GitHub Actions Secret，服务器和仓库只保存公钥。
- Google 直连失败时，页面回退到最近一次成功数据并明确显示数据日期。
- 保留 ECS 原有直连任务作为探测通道，不影响已入库的趋势历史。

## 验证

- 11 项自动化测试通过。
- Next.js 生产构建通过。
- 签名篡改和过期请求均被拒绝。
