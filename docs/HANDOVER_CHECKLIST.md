# 交接与验收清单

## 产品负责人

- [ ] 阅读 `README.md` 和 `docs/PROJECT_STATUS.md`。
- [ ] 确认当前 81 条候选中，76 条是公开趋势而非真实 Listing。
- [ ] 提供首批真实商品范围：站点、类目、关键词和目标 ASIN 数量。
- [ ] 确认五维评分阈值和周报收件人。

## 数据负责人

- [ ] 按 `docs/DATA_INGESTION.md` 输出标准 CSV。
- [ ] 提供稳定的 HTTPS 下载地址。
- [ ] 核对 ASIN、站点、币种和搜索量周期。
- [ ] 首次导入后抽查至少 10 条商品与原始页面一致。
- [ ] 连续观察 7 天采集日志和每日快照。

## 开发/运维负责人

- [ ] 从安全渠道取得 ECS、数据库和环境变量权限。
- [ ] 确认 `.env`、Key、密码和 SSH 私钥没有进入 Git。
- [ ] 执行 `npm ci`、`npm run build` 和 `git diff --check`。
- [ ] 检查两个容器、磁盘、内存、Swap 和 cron。
- [ ] 检查每日备份并完成一次恢复演练。
- [ ] 配置域名、HTTPS、登录限流和云监控。
- [ ] 删除临时 SSH 公钥并轮换临时凭据。

## 首次真实数据验收

- [ ] 真实 ASIN 数量大于 50。
- [ ] 数据库中不存在相同 ASIN + 站点的重复记录。
- [ ] 价格、BSR、评分和评论数可追溯到采集源。
- [ ] 连续 7 个采集周期成功，失败时有明确日志。
- [ ] 至少一个产品形成多日趋势快照。
- [ ] AI 评分没有覆盖事实字段。
- [ ] 周报能区分公开趋势、部分数据和真实数据。

## 当前交接结论

系统已经具备内部试用和真实数据接入的技术基础，但真实 Listing Feed、HTTPS、细粒度
权限和恢复演练尚未完成。完成以上 P0/P1 清单后，才适合扩大内部使用范围。
