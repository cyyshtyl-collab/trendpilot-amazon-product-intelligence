## 业务变化

- 将数据成熟度拆分为“市场评估就绪、待询价、最终决策就绪”三级状态。
- Listing 的价格、BSR、评分和评论数完整后即可进入市场初筛。
- 缺少采购成本的商品明确显示为“待询价”，不再阻塞市场研究。
- 最终决策仍严格要求 Listing、趋势和毛利证据全部完整。
