# 项目状态与路线图

更新日期：2026-09-15

## 1. 项目目标

TrendPilot 将多渠道市场信号统一为可复核的亚马逊选品决策。系统强调“有来源、
可追踪、可解释”：真实商品指标来自采集源，AI 只负责评分、摘要和文案，不负责
编造市场数据。

## 3. 四阶段完成度

### 阶段 1：数据采集 — 约 70%

已完成：手工录入、标准 CSV 导入、自动 CSV Feed、ASIN + 站点去重、每日快照、
采集日志、Google Trends 定时采集和 36 个常用品类录入提示。

待完成：配置真实 Listing CSV 地址，导入首批真实 ASIN、价格、BSR、评分、评论数，
并增加评论明细采集和失败告警。

### 阶段 2：趋势分析 — 约 75%

已完成：候选筛选、排序、趋势周期、历史快照、异常预警和公开趋势信号审核。

待完成：真实商品连续采集 7–30 天后校准阈值，并增加类目基准和竞品对比。

### 阶段 3：AI 评分 — 约 80%

已完成：SiliconFlow、五维评分、结论、差评痛点、卖点草稿、运行日志和回退算法。

待完成：真实评论接入后的提示词评测，以及用户级 AI 权限和费用配额。

### 阶段 4：决策产出 — 约 70%

已完成：周报生成、数据库保存、下载、候选排名和建议清单。

待完成：飞书/企业微信推送、审批状态、负责人和复盘结论。

## 4. 数据质量分层

| 标签 | 含义 | 可用于什么 |
| --- | --- | --- |
| 公开趋势 | Amazon 官方公开的产品方向，无 Listing 指标 | 建立候选池、拓展品类 |
| 待市场验证 | 为补齐类目覆盖建立的产品方向 | 进入趋势和 Listing 验证队列 |
| 部分数据 | 已有部分价格、搜索量或 ASIN | 初筛与待补充 |
| 真实数据 | ASIN、价格、评分等关键字段较完整 | 趋势、评分和周报决策 |

当前 76 条方向属于“公开趋势”，108 条属于“待市场验证”；两者都不能当作真实
Listing 快照或销量证明。

## 5. 当前阻塞与风险

1. **真实 Listing 源未配置（最高优先级）**：自动化已具备，但
   `CANDIDATE_FEED_URL` 为空，因此任务安全跳过。
2. **无 HTTPS**：登录凭证经过 HTTP 传输，不适合跨不受信任网络使用。
3. **权限粒度较粗**：管理员和成员都能访问主要业务接口，尚无只读角色和操作审计。
4. **采集稳定性未验证**：真实 Feed 尚未连续运行，重试、限流和字段漂移需要实测。
5. **资源余量有限**：2GB 级内存适合当前内部规模，不适合高并发和大批量抓取。

## 6. 推荐路线图

### P0：形成真实数据闭环

- 提供可下载的 HTTPS CSV 地址并配置 Feed。
- 导入 50–200 个真实 ASIN，验证去重、快照和采集日志。
- 连续运行 7 天，检查字段漂移和失败率。

验收条件：真实 ASIN 大于 50；连续 7 次采集成功；同一 ASIN + 站点不重复。

### P1：内部正式使用

- 绑定域名并启用 HTTPS。
- 增加只读/编辑/管理员权限和关键操作日志。
- 接入飞书或企业微信周报推送。
- 完成一次数据库恢复演练。

### P2：扩大规模

- 增加类目基准、竞品组和关键词组。
- 增加采集重试、失败告警和指标监控。
- 数据量或并发明显增长后再评估 RDS、对象存储和队列。
